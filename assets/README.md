# Assets Directory

This directory contains media files for my GitHub profile.

## Structure

- `images/` - Profile pictures, icons, and other images
- `banners/` - Header banners and cover images

## Usage

Example:
```markdown
![Profile Banner](./assets/banners/profile-banner.png)
```

## Recommended Sizes

- **Profile Banner**: 1200x400px
- **Profile Image**: 400x400px (square)
- **Project Screenshots**: 800x600px
